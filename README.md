# 💬 LM Studio Companion

Локальный помощник для LM Studio: читает сайты, помогает работать с памятью и показывает состояние подключения в понятной панели. Вы продолжаете общаться в привычном чате LM Studio.

**Версия панели: 0.1.5 · Windows x64 · Обновлено 30 октября 2026**

## ✨ Что уже работает

| Возможность | Что можно сделать |
|---|---|
| 🌐 Интернет | Попросить прочитать ссылку, найти сведения или рассмотреть картинку по URL. Видны источники и причины отказа доступа. |
| 🧠 Память | Посмотреть, добавить, исправить и забыть записи через панель; экспортировать постоянную память. |
| 💬 Память в чате | Подключить общие записи к ответам. Команды «запомни / исправь / забудь» готовят предложения, которые вы подтверждаете в панели. |
| 📦 Перенос памяти | Выбрать записи из offline-копии прежнего persistent-memory, перенести с резервной копией и при необходимости отменить перенос. |
| 🖥️ Советник по модели | Получить оценку подходящих настроек под железо. Советник ничего не применяет и не перезагружает модель. |
| 🔌 Панель и диагностика | Проверить соединение с LM Studio, увидеть доступность функций и понятные сообщения об ошибках. |
| 🛠️ Windows-установка | Установить или обновить панель, откатить версию и удалить её с сохранением пользовательских данных. |

Веб и память работают через собственный плагин **aladushek04/companion-web** вместе с **context-compressor**. У интернета есть режимы **«Интернет выключен / Авто / Исследование»**; память подключается отдельно.

## 🚀 Быстрый старт

### Из исходников GitHub

1. Скачайте исходники нужной ветки и распакуйте в отдельную папку.
2. Откройте **Install-Companion.cmd**. Первая подготовка требует интернета: нужные Node/npm, зависимости и сборка подготавливаются автоматически.
3. После подготовки откройте **Start-Companion.cmd** в папке исходников. Браузер покажет локальную панель; консоль оставьте открытой.
4. Для подключения запустите локальный API-сервер LM Studio. Адрес по умолчанию — **http://127.0.0.1:1234**.

Остановить панель можно через **Ctrl+C** в её консоли. Закрытие вкладки браузера само по себе сервис не останавливает.

### Если у вас готовый Windows-архив

Распакуйте **LMStudioCompanion-0.1.5-win-x64.zip** и откройте **Install-Companion.cmd**, затем **Start-Companion.cmd** в папке установки. Для переносного запуска используйте Start прямо из распакованной папки. Node уже включён; npm и Docker для самой панели не нужны.

Готовая сборка находится в [GitHub Releases](https://github.com/Aladushek04/LMStudioCompanion/releases/latest). Выбирайте файл **LMStudioCompanion-0.1.5-win-x64.zip** в разделе Assets. Автоматические **Source code (zip/tar.gz)** и ZIP с кнопки **Code → Download ZIP** содержат исходники и требуют подготовки, описанной выше.

**Панель и плагин чата устанавливаются отдельно.** Установка панели не включает автоматически веб и память в LM Studio. Вебу нужно подготовленное Python-окружение; порядок подключения и ограничения описаны в [инструкции](docs/USER-GUIDE.md) и [отчёте веб-интеграции](docs/research/stage-b-completion.md).

Советник запускается отдельно: **Start-Advisor.cmd** — [как пользоваться](packages/advisor/README.md).

### 📄 Следующий этап: документы

Реализация будет идти отдельными заходами, с проверками и коммитом после каждого:

- [x] **D0** — проверить файловый API и определить границы подключения; нативная интеграция проверяется в D4.
- [x] **D1** — реализовать адаптер чтения TXT/PDF, проверку входов, состояния и отмену; без экрана и чата.
- [x] **D2** — экран документов, статусы, отмена, повтор и просмотр извлечённого текста; пока без отправки в чат.
- [x] **D3** — подбор фрагментов, текстовые разделы, точный просмотр источника и бюджет на токенизаторе загруженной модели; без чата.
- [ ] **D4** — подключить документы к чату и режимы ответа.
- [ ] **D5** — провести приёмку и собрать готовый комплект.

[Подробности D0–D5](docs/plans/04-documents-stages.md) · [Результаты D0](docs/research/documents-api-report.md) · [Проверки адаптера D1](docs/research/documents-d1-check.md) · [Экран D2](docs/research/documents-d2-check.md) · [Подбор D3](docs/research/documents-d3-check.md). Постоянные библиотеки папок относятся к **G**. OCR сканов не входит в первый выпуск документов.

**Публичные релизы выходят после завершения полных этапов**, а не каждого подэтапа. Подэтапы получают коммиты и локальные проверочные сборки. Первый публичный выпуск **v0.1.5** объединяет принятые результаты A–C; следующий плановый релиз — после приёмки D. [Правила выпуска](docs/RELEASING.md).

Обновление из самого окна Companion запланировано: проверить версию → скачать → подтвердить установку → перезапустить. В 0.1.5 обновление пока выполняется вручную через установщик. [План обновлений](docs/requirements/in-app-updates.md).

## ℹ️ Что важно знать

- В чат сейчас подключается **только общая память**. Проектные записи хранятся в панели, но их подстановка и временная память чата ждут безопасной привязки к чату.
- Сохранение из чата требует вашего подтверждения. Ручные правки имеют приоритет. Удаление записи прекращает новую подстановку, но не стирает старую переписку и сводки сжатия.
- Откат переноса доступен до следующей постоянной правки. Исходный файл прежней памяти не изменяется.
- «Исследование» читает несколько результатов одного поиска; самостоятельный многошаговый исследователь ещё не реализован. Источник помогает проверить происхождение текста, но не гарантирует истинность ответа модели.
- Профили не применяются автоматически, Thinking не переключается Companion, документы ещё не подключены. Существующий чат и инструменты остаются в LM Studio.
- Личная память, переписки, токены и пользовательские настройки не входят в репозиторий. Голос исключён, захват рабочего стола отложен; просмотр веб-изображений поддерживается.
