# LM Studio Companion

Проект удобной локальной надстройки для LM Studio: поиск и просмотр сайтов, понятная память, работа с документами, профили загрузки и управление Thinking.

**Рабочая папка:** `G:\Projects\LMStudioCompanion`.
**Репозиторий:** [Aladushek04/LMStudioCompanion](https://github.com/Aladushek04/LMStudioCompanion).
**Состояние на 29 октября 2026:** реализованы автономный советник по настройкам 0.1.0 и первый read-only срез этапа 00: общие контракты, диагностика возможностей и консервативный выбор интеграции. Советник: **Start-Advisor.cmd**, [инструкция](packages/advisor/README.md). Диагностика: **Diagnose-Companion.cmd**, [инструкция](packages/host/README.md), [результаты проверки](docs/research/capability-report.md). Панель и остальные пользовательские модули пока запланированы. В `packages/web-tools` сохранена копия существующего веб-инструмента 1.1.0 без личной конфигурации; действующая установка продолжает использовать прежнюю папку.

## Основной подход

Предложение автора планов: одна локальная панель управления и один комплект установки с небольшим адаптером LM Studio. Общение остаётся в LM Studio. Панель нужна для списков памяти, документов, профилей и диагностики; её не требуется открывать для каждого вопроса.

Окончательный способ подключения к циклу генерации выбирается после проверки совместимости с `context-compressor`. Два независимых обработчика генерации одновременно не предполагаются. Встроенные настройки и статусы LM Studio используются там, где их достаточно; произвольная вкладка внутри LM Studio не обещана.

## Важное при продолжении

Планы — предложение к реализации, а не утверждение, что будущие функции уже работают. Начат этап 00: первый отчёт выбирает tools-only, а совместимость нового владельца генерации, Thinking и постоянные FileHandle остаются unknown. Само решение по отчёту не переключает LM Studio. Отсутствие подходящего API считается результатом проверки, а не поводом подменять функцию припиской в промпт.

Существующие чаты, база памяти, установленные плагины и конфигурация MCP в рамках создания этого проекта не менялись. Секреты, база памяти и содержимое переписок в проект не скопированы.
