# LM Studio Web 1.1 — проверка визуальных функций

Дата: 29 октября 2026. Windows, Docker Desktop, i5-12400, 32 ГБ RAM,
RTX 4060 Ti 16 ГБ. Модель: Gemma4 12B QAT HauhauCS Balanced Q4_K_M,
контекст 32 000. Другие модели не загружались.

## Подтверждено

- 41 тест прошёл в Docker с ограничениями 2 CPU / 2 ГБ RAM / read-only FS /
  без root и capabilities. Включены реальные Chromium-тесты: JavaScript,
  загрузка изображения на странице, пиксели снимка и вертикальная прокрутка.
- Ruff: без ошибок. Прежние поиск, текстовое чтение, кэш и ограничения сети
  проходят вместе с новыми функциями.
- Контрольная картинка без текстовой подсказки о содержимом: Gemma правильно
  описала зелёный треугольник слева, фиолетовый круг справа и число 73.
- `inspect_image` через настоящий MCP скачал логотип Python, отправил реальные
  пиксели в локальный API и получил описание двух сине-жёлтых змей и надписи.
- `inspect_page` через MCP открыл python.org с изображениями, получил снимок
  1280×900 и визуальное описание страницы. Возвращены URL картинок и координаты
  области, высота документа 2677 пикселей в этом конкретном запуске.
- Оба инструмента вернули по одному настоящему MCP ImageContent JPEG-превью.
- Полная обычная диагностика из установленной папки прошла: пять MCP-инструментов,
  поиск SearXNG, HTTPS-чтение, поиск по кэшу, Chromium, запрет localhost-источника.
- Независимое ревью: критических проблем не найдено. Исправлено падение текстового
  чтения из-за неверного URL картинки (воспроизведено падающим тестом, затем тест
  прошёл). Улучшена проверка бюджета ожидающих запросов и обновлены требования API.

## Проверка в интерфейсе LM Studio

Контрольный чат с context-compressor и lmstudio-web создан отдельно от пользовательских
чатов; persistent-memory в нём отключён. Вложенный вызов `inspect_image` завершился
успешно при Parallel=1: модель описала логотип и отобразила настоящее изображение
прямо в итоговом ответе. Подтверждено снимком интерфейса, а не только JSON-ответом.
Затем в том же чате `inspect_page` выполнил вложенный vision-вызов и вернул
снимок python.org. Gemma описала его и показала реальный скриншот в итоговом
ответе. Подтверждено в интерфейсе: обе картинки отображаются в ответах.

## Практические границы

Скриншот охватывает один видимый участок страницы; для продолжения есть scroll_y.
Превью уменьшено до 1280 пикселей по длинной стороне; ссылка на исходник сохраняется.
Фотографии, не прошедшие загрузку, не описываются по alt-тексту. Сайты могут вернуть
403, и Chromium не гарантирует доступ к заблокированному ресурсу.

Отображение MCP-превью и анализ пикселей — отдельные механизмы. Vision выполняется
через API, а не за счёт надежды на автоматическую передачу MCP-изображения в основную
генерацию. Модель по-прежнему может неточно интерпретировать изображение или не вызвать
инструмент без явного указания. Тесты не гарантируют точность любого будущего ответа.
