# Приёмка: проверяется поведением, а не обещаниями

Это будущий checklist реализации. Незачёркнутые пункты не означают провал текущей документации: функций ещё нет.

## Удобство

- [ ] Первый запуск показывает, что уже работает и что требует настройки, без редактирования JSON пользователем.
- [ ] Пользователь может выполнить каждую основную операцию за 1–3 понятных действия после открытия нужного раздела; расширенные настройки скрыты отдельно.
- [ ] Чат остаётся в LM Studio. Для обычного чтения статьи не нужны имена инструментов.
- [ ] Ошибки объясняют причину и доступный следующий шаг: «Сайт запретил доступ», «Не найдены фрагменты», «Настройки применятся после ответа».
- [ ] Есть отмена, состояние занятости, доступ с клавиатуры и отсутствие незаметной потери данных.
- [ ] При нехватке контекста сохраняется резерв под ответ; материалы текущего запроса имеют приоритет над закреплёнными предпочтениями, а те — над дополнительным поиском и обычной памятью. Сокращение истории сохраняет совместимость с context-compressor; пропуски материалов показаны пользователю.
- [ ] Визуализация состояния в чате имеет переключатель в настройках плагина. Проверены её стоимость по фактическому входу модели, отсутствие дополнительной генерации, сохранность предупреждений/сжатия и поведение при неизвестных метриках. UI-only режим не добавляет токенов; если это не доказано, функция по умолчанию выключена с объяснением. См. [ТЗ](requirements/chat-visualization.md).

## Интеграция

- [ ] В обычном запросе появляется один ответ; context-compressor, tools и картинки сохранены.
- [ ] При недоступном API функция явно недоступна, а не изображает успех.
- [ ] При Parallel=1 фоновые задачи не блокируют собственную основную генерацию.
- [ ] Установка/откат сохраняют чужие MCP-записи и прежний выбор обработчика.

## Модули

- [ ] Профили: dry-run не меняет загруженную модель; применение не прерывает ответ; есть реальный возврат.
- [ ] Thinking: шаблон и фактический thought-канал подтверждают fast/deep; один лишь скрытый UI-блок не засчитывается.
- [ ] Память: запись видна после restart; исправление видно; после удаления запись не подставляется в новом чате; scope isolation проверена. Старый чат может содержать прежний текст, что явно объясняется.
- [ ] Ручная правка памяти сохраняет приоритет после позднего фонового результата, повторного извлечения старой формулировки и restart. Противоречащее предложение требует подтверждения; отдельная активная запись со старым фактом автоматически не создаётся.
- [ ] Переключение проекта не меняет привязку существующего чата; временная память не переходит в другой чат и пропадает после перезапуска Companion. При неизвестном chat ID проектная/временная автоподстановка недоступна.
- [ ] Документы: правильный файл/фрагмент открывается из источника; скан без текста не считается прочитанным; 5/5 неответимых strict-вопросов получают отсутствие данных.
- [ ] Документы: работают автоматический подбор фрагментов и явное указание области пользователем; автоматический подбор соблюдает указанную область. Частичный охват показан, нехватка контекста отличается от отсутствия данных; проверка отдельных фрагментов не выдаётся за проверку всего документа.
- [ ] Библиотеки: удалённый или обновлённый файл не даёт устаревшие chunks; оригиналы не меняются.
- [ ] Веб: 10 явных просьб прочесть URL без названий функций дают реальные попытки чтения; 5 blocked-фикстур дают 0 заявлений об успешном чтении.
- [ ] Исправления: не больше 1 syntax repair на ход; аргументы проходят schema validation; writes не повторяются автоматически.
- [ ] Источники: проверены IDs текущего хода, но UI не объявляет их сертификатом истинности.

## Ресурсы и доказательства

- [ ] Отдельно записаны оценка памяти, измеренная скорость, latency первого токена, версии модели/runtime и дата.
- [ ] Накладные расходы панели/памяти измеряются отдельно от основной генерации; нет обещаний «мгновенно».
- [ ] Отчёт 12B не выдаётся за проверку 26B. Длинный контекст и изображения проверяются отдельными сценариями.
- [ ] В отчёте перечислены реально выполненные команды и ограничения, без личных документов, памяти и переписок.
