# D2: экран документов

Основа: [разбивка D](04-documents-stages.md), контракт D1. Выполнение inline, без нового релиза и без D3/D4.

## Контракт

- Рабочий набор в RAM, отдельный случайный ID на вкладку, не сохраняется после перезапуска. До четырёх наборов, каждый до пяти файлов, 8 MiB на файл / 20 MiB суммарно. Через 30 минут без обращений набор удаляется. Выбор не привязан к чату и никуда не подставляется.
- Передаются только выбранные браузером байты TXT/PDF. Никаких серверных путей. Резервировать число/размер до чтения тела; превышение и оборванная загрузка не публикуют файл. Существующие Host/Origin/Bearer-защиты обязательны.
- Загрузка заканчивается принятием в очередь; HTTP не ждёт парсера. Один активный разбор на сервер; отдельный SDK-клиент на попытку. По окончании/отмене закрыть клиент. Не запускать следующий разбор до окончания сырого вызова предыдущего backend. При зависшем backend очередь честно остаётся занятой.
- Собственные UUID и ревизии элементов сохраняются при повторе. Результат D1 хранит свои hash/version/locators. Поздние события отменённой/удалённой попытки игнорируются. Отмена немедленно исключает текст и выбор; оригиналы не изменяются.
- Список не содержит полного текста/байтов/SDK handles. Просмотр — отдельное чтение готового результата, экранированный текст без HTML. Выбор разрешён только готовым файлам и изначально выключен.
- Статусы: очередь, обработка, готов, текст не извлечён, ошибка, отменено. Повтор после ошибки/отмены; удаление из набора в любой момент. Причина ошибки видна. Главы/страницы не выдумываются: D1 отдаёт только общий диапазон текста, ограничение областей отложено до D3.

## Порядок

1. RED: тесты API, изоляции, квот/резерваций, отмены/повтора/позднего результата, закрытия; GREEN: владелец RAM, маршруты и подключение сервера.
2. Форма выбора файлов, список статусов/выбора, просмотр текста, отмена/повтор/удаление. Навигация сохраняет набор; при обновлении страницы восстанавливается только ID из sessionStorage, истёкший набор создаётся заново с объяснением.
3. Браузерная проверка Edge с синтетическим backend через настоящий host: TXT/PDF/скан/ошибка, отмена/повтор/выбор, клавиатура, 320 px и 200% текста, pageerror/HTML escaping. Минимальная native API-проверка только фиксированных fixtures, без генерации/переключения модели.
4. Полные тесты, typecheck/build. Одно независимое итоговое ревью; один RED→GREEN проход существенных замечаний, затем регрессии. Обновить руководство/roadmap/отчёт, commit/push текущей ветки. Остановиться перед D3.

## Приёмка

Проверки фиксируют реальные ответы API и DOM. Отсутствие OCR, страниц/глав и отправки в чат отражается в интерфейсе. Сборка и проверка не меняют опубликованный v0.1.5.
