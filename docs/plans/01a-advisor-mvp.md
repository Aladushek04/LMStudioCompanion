# Советник 0.1.0 — реализованный автономный срез

Поручение пользователя: «Сделай тогда советника», после предложения самой простой read-only версии. Выполнен самостоятельный первый этап пункта 1; это не завершение всего плана 01.

## Пользовательский результат

- [x] Запуск одной кнопкой из `G:\Projects\LMStudioCompanion\Start-Advisor.cmd`.
- [x] Обычное окно Windows: аппаратные ресурсы, скачанные LLM, выбранная модель, таблица и объяснение рекомендации.
- [x] Контексты 16К/32К/64К в пределах metadata; частичный GPU Offload при необходимости.
- [x] Раздельная оценка общей ёмкости и свободной сейчас памяти; unknown остаётся unknown.
- [x] Фоновая проверка, отмена, копирование параметров, сохранение JSON-отчёта.
- [x] Только CLI dry-run; API-сервер, Node.js, Python, Docker и изменение генератора не нужны.
- [x] Нет изменения модели, настроек LM Studio, памяти, MCP или сторонних плагинов.

## Отличия от большого плана

Небольшой самостоятельный модуль реализован на Windows PowerShell 5.1 и Windows Forms, с тонким C#-host для обычного exe-запуска без консоли. Это решение автора ради простого запуска на текущем Windows-компьютере. TypeScript-панель и общий host не нужны для read-only проверки, они остаются в долгосрочном плане.

Пригодность профиля предварительная: память оценивает CLI, скорость не измеряется. Общие 2 ГиБ GPU/4 ГиБ RAM — политика запаса, не гарантия отсутствия OOM. Total Memory сравнивается с RAM консервативно. Подробные ограничения описаны в [инструкции](../../packages/advisor/README.md).
