# D0: проверка файлового API — Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Только D0; продуктовый адаптер, экран и подключение к чату относятся к D1–D4.

**Goal:** Проверить фактические API и границы TXT/PDF на установленной версии без генерации и автозагрузки моделей.

**Architecture:** Read-only исследование SDK/rag-v1 и отдельный SDK-клиент с небольшими синтетическими файлами. Установленные плагины и настройки чатов не меняются. Результаты — воспроизводимый probe, fixtures и отчёт verified/unsupported/unknown.

**Tech Stack:** Локальный @lmstudio/sdk 1.5.0, Node, bundled reportlab/pypdf/Poppler для фикстур; существующие контракты. Дополнительные зависимости не устанавливать.

**Spec:** [D0](04-documents-stages.md), [план 04](04-documents.md), [DESIGN](../DESIGN.md).

## Task 1: исходники, лицензия и синтетические файлы

- [x] Проверить package/manifest, наличие лицензии, parsing/retrieval и границы обработки у установленного rag-v1. Чаты, install-state и plugin-data не читать.
- [x] Создать TXT, небольшой текстовый PDF и PDF с изображением без текстового слоя; проверить текст/отсутствие текста независимым pypdf и отрисовать обе страницы Poppler. Только вымышленные факты.
- [x] Установить возможность отмены, locators, обязательность embedding и срок жизни handle по исходникам SDK; не принимать декларации за доказательство live-работы.

## Task 2: воспроизводимая проверка

- [x] scripts/check-documents-api.mjs: ограниченные входы только из fixtures, prepareFile и prepareFileBase64, parser identification, parseDocument, same-name identity, cancellation, invalid handle; записывать только синтетические результаты и ошибки без локальных путей.
- [x] Retrieval проверить без неявной загрузки: отсутствие embedding даёт честную причину; если уже загружена embedding, использовать только этот конкретный экземпляр. При отсутствии не загружать модель, успешный поиск оставить unknown.
- [x] Проверить передачу собственных файлов в ChatMessage и сохранность изображений; не читать историю действующих чатов. Отдельными короткоживущими процессами проверить ссылку на собственный handle после disconnect. LM Studio ради restart не перезапускать: такую проверку оставить unknown.
- [x] Expected: probe завершён с подробными фактами, загруженные модели до/после совпали; без LLM generation и настроек. Неподдержанный endpoint/парсер фиксируется как результат исследования, не маскируется fallback.

## Task 3: решение для D1 и итог

- [x] docs/research/documents-api-report.md и reference/documents-d0-check.json: версии, лицензия, фактические content/metadata, ограничения и выбранная граница адаптера, фильтрация области, открытие фрагмента, совместимость с компрессором и strict-mode gate.
- [x] Зафиксировать предлагаемые пределы первого адаптера и отмены; state ready не обещает готовый retrieval. Невозможность полного строгого режима в D0 не выдавать за его реализацию.
- [x] Уместные проверки probe/fixtures, typecheck, одно независимое итоговое ревью и исправления существенных замечаний; обновить README/ROADMAP/подэтапы, commit/push. Без нового архива или GitHub Release. Остановка перед D1.

Результат: [отчёт D0](../research/documents-api-report.md); 174 теста / 32 файла, typecheck/build, одно ревью и один проход исправлений. Продуктовый D1 не начат, новый релиз не публиковался.
