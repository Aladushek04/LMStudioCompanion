# CORE-1 — собственный цикл ответа

**Goal:** В пустом тестовом чате Companion Core сам ведёт ответ и сторонние инструменты, показывает состояние, корректно отменяет ход и освобождает ресурсы.

**Architecture:** Вокруг сохранённого алгоритма сжатия выделяется собственный жизненный цикл `src/companion/turn.ts`. Он один раз получает историю/модель/сессию инструментов, передаёт их обработчику и закрывает сессию на всех путях. Будущие память и веб подключаются через внутренние точки расширения без второго владельца ответа. Текущие A–C и документы не меняются.

**Tech Stack:** Комплектный Node 24.22.2, SDK 1.5.0, TypeScript, Vitest, локальная сборка esbuild; нативная проверка на установленной LM Studio и уже загруженной модели.

**Spec:** [CORE-1](07-companion-core-stages.md), [требования](../requirements/companion-core.md).

## Решения

- Используется текущая рабочая ветка и отдельный пакет Core. Второй ИИ параллельно меняет общие конфигурации/тесты; они не редактируются и не включаются в наши коммиты. Новый worktree здесь не требуется: перенос сборки/установки в другую папку добавил бы второй набор путей при уже разделённых файлах.
- Субагенты не запускаются: реализация и итоговое ревью выполняются основным агентом, без заявления о независимом ревью.
- Включение только в заранее открытом пользователем пустом тестовом чате. Установленные сторонние плагины не редактируются. Собственный ID и кэш уже отделены.
- Общий runtime проекта не меняется. У Core проверены Node 24.22.2 (комплект панели) и Node 25.5.0 (runner LM Studio 0.4.28); оба major разрешены в engines и проверке запуска. Это не расширяет поддержку Node 25 у SQLite-хранилища панели.
- Память CORE-2, веб CORE-5 и документы D4 не включаются. Проверка изображения относится к сохранности входа, а не к новому анализатору документов.

## Задачи

- [x] RED→GREEN: жизненный цикл. `packages/conversation-engine/tests/companion/turn.test.ts`; `src/companion/turn.ts`. Контракт `CoreTurn` содержит id, signal, source, history и tools. `runCompanionTurn(ctl, runner, hooks?)` возвращает completed/cancelled/error, показывает русский статус; hooks — внутренние prepare/after без включённых продуктовых функций.
- [x] Сессия освобождается ровно один раз после успеха/ошибки/отмены/исключения hook. Поздняя сессия после отмены тоже закрывается. Ошибка получения инструментов не вызывает runner. Неподдержанный источник токенов не вызывает вложенный generator fallback.
- [x] Подключить обработчик к `CoreTurn`, убрать дублирующее получение history/source/session и вложенные освобождения; сохранить прежние алгоритмы и тесты сжатия. Полный ход проверен на поддельной модели: обычный ответ, вызов и продолжение, ошибка инструмента, следующий успешный ход, вложение и отмена.
- [x] Русские статусы владельца/ошибок и название Companion Core; перевод собственных настроек. Структурные маркеры summary и алгоритм переписывания контекста сохранены. Полная локализация сжатия остаётся для следующих подэтапов.
- [x] Typecheck и **387/387** тестов на Node 24.22.2 и 25.5.0; сборка/установка своего пакета и контроль сохранности companion-web. Версии приложения/SDK/runner зафиксированы без чтения личных чатов и конфигов.
- [x] В пустом чате проверены простой ответ, /usage, сторонний инструмент и продолжение, разрешение/отказ, следующий ход, изображение, остановка и возврат к прежнему обработчику. Модель не менялась.
- [x] [Отчёт](../research/core-1-check.md) и актуализация готовы; реализация зафиксирована отдельным коммитом `b32f22d`, только свои файлы. Работа останавливается на CORE-1; CORE-2 не начат.

## Проверки

Из корня, `$node` — проверенный `releases/LMStudioCompanion-0.1.5-win-x64/runtime/node.exe`:

```powershell
& $node node_modules/vitest/vitest.mjs run --config packages/conversation-engine/vitest.config.mts --maxWorkers=1 --no-file-parallelism
& $node node_modules/typescript/bin/tsc -p packages/conversation-engine/tsconfig.json
& $node scripts/build-conversation-engine.mjs
```

Нативная приёмка не подменяется моками или unit-тестами. Непройденные пункты остаются незавершёнными с причиной; не переходить автоматически к CORE-2.
