# D2: экран документов

Дата: 2026-10-30. [План](../plans/04-documents-d2.md), [контракт D1](documents-d1-check.md), [машинный отчёт](../../reference/documents-d2-check.json). Экран работает в сборке из текущих исходников; опубликованный ZIP **v0.1.5 не обновлялся**.

## Что доступно

В разделе «Документы» можно явно добавить TXT/PDF, увидеть очередь/обработку/готовность/ошибку/отмену, повторить неудачную попытку, посмотреть извлечённый текст, выбрать или исключить готовый файл и убрать его из списка. Очистка набора не изменяет оригиналы. Одноимённые файлы различаются собственными UUID и отпечатками содержимого.

Рабочие наборы временные, в RAM владельца host: максимум четыре, в каждом до пяти файлов / 20 MiB, отдельный файл до 8 MiB. Через 30 минут без обращений набор удаляется; скрытая вкладка не продлевает срок опросом. Набор создаётся при первой загрузке; очистка освобождает слот. Обновление страницы восстанавливает ID, если набор ещё существует, уже при запуске приложения на «Обзоре». Новая навигация начинает пустой набор, даже если браузер скопировал sessionStorage. Браузерная exclusive Web Lock не позволяет новой вкладке с копией sessionStorage разделить старый набор; при отсутствии Web Locks восстановление отключено с объяснением. Основание механизма: [W3C Web Locks](https://www.w3.org/TR/web-locks/).

Выбор изначально выключен. Это **выбор только в панели, без подключения к чату**, без retrieval и без подстановки всего текста модели. Главы/страницы не предлагаются: parser builtIn/1 не возвращает подтверждённые metadata. Просмотр показывает экранированный текст, версию и отпечаток, не исполняет HTML или инструкции документа. Наличие текста не подтверждает истинность его утверждений.

## Владение и API

POST /api/documents создаёт набор; GET/DELETE /api/documents/:id читает/очищает его. POST :id/files принимает только octet-stream с именем выбранного файла и известным Content-Length. Размер и слот резервируются **до** чтения тела, переполнение/обрыв освобождают резерв. Пути, JSON-ссылки на файлы, лишние поля и неизвестные действия не принимаются. Все маршруты защищены прежними Host/Origin/Bearer-проверками; изменения требуют Origin и строгих тел.

202 подтверждает постановку в очередь, а не готовность. Один сырой вызов backend на сервер; для каждой попытки отдельный SDK-клиент. В HTTP не удерживается 90-секундный разбор: состояния читаются опросом. Готовность публикуется после закрытия клиента. Отмена сразу исключает результат; timeout виден до окончания некооперативного raw-вызова, следующий разбор ждёт его завершения. Закрытие панели отменяет очередь/активную попытку и закрывает принадлежащий ей клиент. Нельзя гарантировать принудительную остановку серверного парсера; неизвестное завершение не разрешает параллельный повтор.

Действия над элементом требуют ревизию; устаревшее действие даёт 409 и обновление списка. Удалённые/отменённые/просроченные попытки не возвращают поздний текст. Итоговый результат D1 — основание состояния; асинхронный onState не используется как подтверждение доставки. Список не возвращает bytes/handles/полный текст; отдельный preview доступен только готовому элементу и содержит его content/text version.

- API/owner: авторизация, строгие тела/имена, изоляция, одинаковые имена, просмотр версии, выбор/удаление, stale revision, отказ/повтор, отмена/поздний результат, одиночная raw-операция, резервирование слотов/байтов, TTL, закрытие сессии и таймаут.
- Edge, scripts/check-documents-panel.mjs: настоящий HTTP-host, синтетический backend; TXT/PDF/скан/ошибка, повтор, отмена, выбор/исключение, новая и копируемая вкладки, обновление страницы, plain-text escaping, клавиатура, 320 px / 200% текста. Pageerror = 0. Desktop/mobile screenshots просмотрены.
