# Этап 00, задача 2: локальная панель

Основа: [план 00](../plans/00-foundation.md), [DESIGN.md](../DESIGN.md). Рабочая ветка: feat/foundation-panel.

## Решения по объёму

- Исполняется согласованная задача 2: loopback-сервис, состояние функций, собственные настройки и запуск панели. Комплект установки/отката из задачи 3 остаётся следующим шагом.
- Установленный SDK и точка входа context-compressor повторно просмотрены. Регистрация prediction loop есть; доказанной публичной композиции нет. Для этой панели принят предусмотренный планом путь tools-only. Никакие hooks, модели или сторонние файлы не переключаются. Проверка будущего fork с генерацией остаётся отдельной работой, unknown.
- API защищён точным Host, Origin и случайным токеном запуска. Токен передаётся интерфейсу во фрагменте URL, удаляется из адресной строки и не выводится в журнал. Только собственные settings.json; никакой второй записи в memory.db.
- Настройки будущих модулей можно проверить и сохранить через management API, но панель не изображает их применёнными в LM Studio. Пока нет подтверждённого стабильного ID чата, scoped-функции не включаются. ChatScopeStore — только RAM-области запуска; перед фактическим подключением проектной памяти потребуется отдельное постоянное хранение привязок без sessionId.
- Один процесс владеет settings-dir (эксклюзивный lock-файл). После аварийного завершения lock автоматически не удаляется, чтобы не допустить двух писателей; восстановление описывается в инструкции.
- React/Vite выбраны по исходному DESIGN. Версии получены из npm и закреплены; рекомендации modern-web-guidance применяются к доступности, масштабированию текста и состоянию проверки. UI не требует внешних шрифтов или сетевых ассетов.

## Панель и завершение

- RED браузерной проверки: до реализации интерфейса отсутствовала сборка сервера/панели. После сборки сценарии выполняются в отдельном headless Edge с временным профилем, без пользовательских вкладок.
- Проверены подключённое и недоступное состояния API, недоступный раздел памяти, отмена, отсутствие ошибок страницы, клавиатура, 320 px и увеличение текста до 200%. Переполнение длинного заголовка и кнопки при 200% воспроизведено и исправлено переносами текста, без скрытия содержимого.
- Остановка сервиса первоначально могла освободить lock раньше окончания своих операций. Отдельный падающий тест воспроизвёл проблему; сервер теперь ждёт все request-handlers перед освобождением владения папкой. RED→GREEN.
- Самостоятельный live-прогон интерфейса с настоящим API 127.0.0.1:1234 завершился состоянием «LM Studio подключена». Применялись только GET-запросы; генерация и смена моделей не вызывались. Временный сервер проверки остановлен, его папка удалена. Снимок — data/ui/panel-live.png, в Git не включён.
- Итоговый Vitest: **46/46**. Дополнительно проверен отменённый HTTP PUT с неполным JSON: settings.json не создаётся. Проверка типов и сборка прошли.
- Независимый reviewer прочитал diff 46dcd63..532b4eb, не нашёл Critical/Important; полный набор самостоятельно не запускал. Замечания Minor об ошибке открытия lock и смешении unsupported/unknown исправлены. Для unsupported выполнено отдельное RED→GREEN в настоящем интерфейсе; для startup error уточнено сообщение без изменения политики владения.
- `git diff --check` используется с `core.whitespace=cr-at-eol`: исходные CRLF сохраняются по .gitattributes для точных контрольных сумм, а не считаются лишними пробелами.
- UTF-8 BOM scripts/Start.ps1 сохранён для Windows PowerShell 5.1. Скрипт проверяет минимальную версию Node, не устанавливает зависимости и не меняет настройки MCP. Настоящий PowerShell-запуск с -NoOpen проверен из перенесённой сборки в папке с пробелами/кириллицей: HTML панели доступен. Завершено только собственное дерево процессов проверки, временная папка удалена. Файловое хранение также проверялось в временной папке с пробелами/кириллицей. Это не испытание установки на чистую машину.

## Сохранённые границы

- Реальные project/session injection и постоянная привязка к чатам не включены; RAM-store не заменяет будущее постоянное хранение проекта чата.
- Реальная композиция context-compressor, новый владелец генерации и управление Thinking не проверялись и остаются unknown. Панель не повышает эти статусы.
- Автоматический recovery аварийного lock и повторное открытие работающего процесса через второй запуск не реализованы. Инструкция описывает остановку старой консоли и получение нового ключа.
- Установка, поставка runtime и откат на чистом профиле — следующая задача 3. Текущий запуск рассчитан на собранную рабочую папку с зависимостями.

Проверенные срезы сохранены коммитами c8af6b2 (сервис) и 532b4eb (интерфейс/запуск). Последующие уточнения и документация сохраняются отдельным завершающим коммитом. Результаты текущего среза — reference/panel-check.json; контрольные суммы — reference/panel-manifest.json. Манифест foundation-manifest.json остаётся снимком прежнего среза задачи 1, его изменённые теперь файлы не выдаются за неизменённые.
