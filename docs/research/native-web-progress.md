# Подключение веба к чату

Проверено 2026-10-30, LM Studio 0.4.27.0, SDK 1.5.0. Продолжение [этапа B](web-progress.md).

## Что работает

Отдельный плагин `aladushek04/companion-web` регистрирует только prompt preprocessor и настройки. Он не заменяет prediction loop и не импортирует исходники сторонних плагинов. Перед генерацией планирует чтение/поиск, вызывает собственную копию Python-обработки и проверяет schema_version=2. Пользовательские MCP-конфигурации не читаются и не меняются. Существующий веб-MCP остаётся отдельным набором инструментов.

Режимы в настройках чата: «Интернет выключен / Авто / Исследование». Выключение касается автоматики Companion: отдельно включённые сторонние инструменты не отключаются. Исследование пока выполняет один поиск с чтением нескольких результатов, а не самостоятельный многошаговый исследовательский цикл.

В исходное сообщение добавляются реальные источники с URL, ID, статусом, хешем снимка и фрагментами. Добавление производится в копию ChatMessage с сохранением вложений. Источники считаются недоверенными данными. SDK сохраняет обработанное сообщение в истории — отключение плагина не удаляет прежние вставки.

Доступный объём проверяется настоящим токенизатором выбранной модели после применения шаблона ко всей истории и кандидату сообщения. Резерв: максимум из 2048 токенов и 15% окна для ответа, дополнительно 1024 для инструментов; это консервативный резерв, не измеренная стоимость полного набора tools. Если места нет, фрагменты сокращаются со статусом partial; при невозможности поместиться ход останавливается. Переполненная история не передаётся компрессору с заведомо переполненной вставкой.

При недоступности обязательной ссылки препроцессор останавливает ход с причиной. Это предотвращает генерацию пересказа по непрочитанному URL, но LM Studio показывает ошибку генерации и пустой assistant-блок, а не обычный текстовый ответ. Такую форму нельзя выдавать за окончательный UX контролируемого ответа. Показываются реальные статусы источников; тумблер скрывает подробную строку источников, но не текст, необходимый модели.

## Установка из этой рабочей копии

1. Подготовить `.tools/web-venv` с зависимостями веб-инструмента.
2. Выполнить `node scripts/build-native-plugin.mjs` в корне проекта.
3. В `.tools/native-plugin` выполнить `lms dev --install`.
4. В новом тестовом чате включить `aladushek04/companion-web`, выбрать «Авто». Подготовленная локальная сборка содержит пути окружения этой рабочей копии; она не переносима на другой компьютер и не включена в ZIP 0.1.1.
