# Память: обратная связь и приоритеты — 1 ноября 2026

## Причина обращения

На пользовательском скриншоте запрос «запомни новую версию карточки» не создал предложение: плагин сообщил, что изменений нет, но модель заявила об успешном запоминании. Проверка `packages/memory/src/capture.ts` подтвердила ограниченный разбор команды с явным текстом, без разрешения ссылки на предыдущую карточку. `packages/lmstudio-plugin/src/index.ts` передаёт модели статус операции инструкцией; гарантированного контроля её последующего ответа нет.

Эта архитектура сохранения в рамках исправлений интерфейса не менялась. [Продолжение памяти после D](../requirements/memory-next.md) включает обычные просьбы, версии карточек отдельно от личных фактов, выбранные чаты и проверяемый результат записи. Советник/профили E отложены решением пользователя.

## Исправления в исходниках

- «Обновить список» и «Обновить предложения»: текст загрузки, блокировка повторного нажатия, результат с временем и количеством. Результат объявляется через именованные `role="status"` без переноса фокуса.
- При отказе запроса прежний успех убирается, показывается ошибка, повтор доступен. До первого успешного чтения очереди не объявляется, что предложений нет.
- После подтверждения предложения или переноса список тоже сообщает актуальное количество.
- Повторяющиеся предупреждения удалены из основного экрана, технические пояснения и инструкция команд находятся в раскрываемой справке. Подтверждения удаления/перезаписи и действия при реальной ошибке сохранены.
- В обзоре/документации отмечен отложенный советник, обновлены приоритеты. [LM Studio 0.4.28](lmstudio-0.4.28.md) проверена по официальному списку изменений, без смены установленной модели/runtime.
