# Этап B: результат приёмки

Дата: 2026-10-30. LM Studio 0.4.27.0, SDK 1.5.0, текущая Gemma 4 12B. Пользовательский объём этапа B закрыт в совместимом режиме **prompt preprocessor + собственный веб-обработчик**. Владельцем итоговой генерации остаётся `rootmonster/context-compressor`. Новая модель не загружалась, параметры модели не применялись, исходники сторонних плагинов и пользовательская MCP-конфигурация не изменялись.

## Что принято

| Сценарий | Фактический результат |

| Поиск актуальных сведений | Пользователь подтвердил поиск, источники и ответ в настоящем чате; SearXNG работает через существующий порт 8088 |
| Интернет выключен | Планировщик выполняет 0 вызовов; пользовательский скриншот соответствует этому режиму, сторонний MCP был отдельно выключен |
| Режимы | «Интернет выключен / Авто / Исследование» доступны в настройках чата; исследование увеличивает бюджет страниц, уточнения можно задавать следующим сообщением |

Источник для наборов 10/5 — [машинный отчёт](../../reference/web-live-acceptance.json). Это **headless-проверка того же препроцессора/обработчика с настоящей уже загруженной моделью**, а не десять прогонов через интерфейс компрессора. Совместимость и сжатие проверены отдельно в настоящем тестовом чате через Windows UI. Данные тестов синтетические; личные чаты, факты памяти и файлы для них не использовались. [Проверка отмены vision](../../reference/vision-cancellation-check.json) также отделена от проверки штатной кнопки Stop.

## Проверки кода и ревью

- Vitest: **101/101**, TypeScript `tsc --noEmit`: passed.
- Python с установленным Edge: **60/60**, Ruff: passed.
- Сборка host/панели и самостоятельного нативного плагина: passed; штатная установка `lms dev --install` — successful.
- Новые тесты моста сначала дали RED из-за отсутствующей поддержки image/model selection, затем GREEN. Проверен отказ от неявного выбора vision-модели и закрытие ресурсов.
- Независимое ревью выявило ложный GREEN blocked-приёмки при любом backend-сбое. Исправлено: проверяются реальные blocked-записи и полный размер набора; регрессионный тест отклоняет error и неполные наборы. Отдельным RED → GREEN исправлено русское сообщение отмены вместо английского SDK-текста. Генерация маркера проверяется в `nonReasoningContent`, а не во внутреннем рассуждении.
- Один полный TS-прогон под параллельной генерацией не уложил PowerShell-проверку Windows-версии в существующий таймаут 2500 мс. Повтор после завершения нагрузки прошёл целиком; таймаут продукта ради теста не увеличивался.

## Зафиксированный способ выполнения плана

План 06 предполагал несколько возможных способов интеграции. Выбран препроцессор, потому что он сохраняет действующего владельца ответа и позволяет гарантировать чтение до его запуска. Поэтому источники показываются штатными статусами чата, а не новой таблицей в общей панели; при недоступном обязательном источнике ход останавливается до генерации. SDK toolsSession не объявляется проверенным: собственный Python-канал отдельно обозначен как webTransport.

Модель не формирует JSON-аргументы для автоматического чтения: они строятся из плана обычным кодом. Поэтому библиотека узкого исправления JSON остаётся отдельно проверенной; чужой обработчик malformed tool calls не перехватывается и writes автоматически не повторяются. Прежняя обработка компрессора сохранена. Этот результат не является обещанием управлять всеми сторонними инструментами.

## Границы выпуска

- «Выключен» отключает автоматику Companion; сторонние веб-инструменты управляются отдельно.
- «Исследование» пока делает один поиск с чтением нескольких результатов. Самостоятельный цикл уточнения поисковых запросов не реализован.
- Только явная просьба рассмотреть картинку запускает vision. Автоматического визуального обхода плохого извлечения или блокировок нет; CAPTCHA не обходится.
- Источники и интерпретация занимают контекст и сохраняются SDK в истории. Тумблер скрывает подробный статус, а не необходимые модели данные. Есть лимиты страниц, времени, символов и проверка настоящим токенизатором с консервативным резервом ответа/инструментов.
- При остановке препроцессора LM Studio показывает ошибку и пустой assistant-блок. Отдельного обычного ответа об ошибке от нового владельца вывода нет.
- Нет перехвата конечного ответа компрессора, гарантии истинности каждого утверждения или проверки каждого напечатанного моделью ID после генерации. Source ID устанавливает происхождение записи, а не истинность пересказа. Viewer фрагментов в общей панели и расширенный controlled-output остаются дальнейшими возможностями, не скрыто включёнными функциями.
- Установка привязана к подготовленному Python-окружению этой рабочей копии. Она не включена в прежний автономный ZIP 0.1.1; переносимая упаковка всех модулей относится к этапу G. Проверка 12B не переносится на 26B.
