# CORE-1 — проверка собственного цикла ответа

**Дата:** 1 ноября 2026. **Результат:** CORE-1 выполнен в отдельном тестовом чате. Это ещё не приёмка полного Companion Core и не исправление общего запоминания.

Коммит реализации: `b32f22d` (`feat(core): own response lifecycle and native tool permissions`). Документация приёмки фиксируется отдельно.

## Что изменено

- `src/companion/turn.ts` владеет историей, выбранной моделью, отменой и сессией инструментов. Источник получается один раз; вложенного генератора и продолжения без недоступных инструментов нет. Сессия закрывается при успехе, ошибке и отмене; запоздавшая после Stop сессия также освобождается.
- Обработчик использует этот контекст хода. Внутренние `prepare/after` оставлены для следующих подэтапов; встроенные память и веб ещё не подключены. Исходные алгоритмы сжатия и структурные маркеры сохранены.
- Вызовы сторонних инструментов проходят нативное подтверждение LM Studio. Карточка содержит `pluginIdentifier` и `callId`; состояние ожидания — `confirmingToolCall`. Отказ не запускает реализацию; отредактированные аргументы проверяются повторно. Через две минуты без решения ход завершается с явной ошибкой; позднее разрешение действие не запускает.
- Повтор после обрыва связи допускается только до текста, опубликованного запроса инструмента и действия. Используется тот же источник, без повторного получения модели и JIT-перезагрузки. Stop прерывает паузу. Если SDK завершает отменённый `act()` обычным возвратом, незавершённое reasoning не превращается в итоговый ответ.
- Свои настройки и статусы жизненного цикла переведены на русский. `/core` и `/core-status` показывают активного владельца, версию, runtime и число инструментов без генерации. Диагностические команды не попадают в последующие запросы модели.
- Версия пакета `0.1.0-core1`, manifest revision 2; SDK закреплён на 1.5.0 с lock-файлом. Локальная сборка пишет SHA-256 и версии в `build-manifest.json`; сама команда ничего не устанавливает и не включает.

## Проверки в нативном чате

Пользователь открыл новый пустой чат. Включён только один владелец ответа: `aladushek04/companion-core`; companion-web и rootmonster/context-compressor выключены. Для инструментов временно включён официальный `lmstudio/js-code-sandbox` — это tools provider, не второй генератор. Личные чаты не открывались, в память ничего не записывалось.

Во время интеграции обнаружены и исправлены: ожидание подтверждения без кнопок из-за отсутствующего `pluginIdentifier`, а также выдача незавершённого reasoning после Stop. Для обоих случаев добавлены регрессионные тесты; итоговый прогон выполнен после исправлений.

Финальное состояние тестового чата: Core включён, JS sandbox, companion-web и context-compressor выключены. В остальных чатах плагины не переключались. Уже загруженная Gemma4 12B Q4_K_M осталась единственной моделью: контекст **64000**, parallel **1**; в конце idle, очередь 0.

## Сохранность и границы

- SHA-256 установленного bundle совпал с локальным кандидатом: `216b639e147726d2fba7ba0da6cce401e8a9387ad615e0108583d59bdc1d88e0`.
- Четыре публичных файла прежнего companion-web (`manifest.json`, package/lock, src/index.ts) совпали с контрольной копией до установки. Исходники сторонних плагинов не редактировались.
- Проверены публичные методы SDK 1.5.0; prediction-loop API помечен разработчиками SDK как ещё развивающийся. Совместимость подтверждена на указанной версии LM Studio, не обещается для любой версии.
- Полная локализация отчётов сжатия остаётся впереди. Структурная метка `[context-compressor]` в `/usage` сохранена. В reasoning текущей модели заметен служебный LSEP-маркер; его очистка этим подэтапом не реализована. При Stop до первого токена LM Studio может показать свой текст о пустом сообщении рядом с русским статусом остановки.
- Длинное сжатие, память, карточки и встроенный веб в одном цикле здесь не приняты: это CORE-2–CORE-7. CORE-2 не начат. Документы остаются приостановлены.
- Ревью выполнено автором без субагентов. Завершённого независимого ревью нового Core нет. Файлы тестов другого ИИ и старые черновики памяти не включаются в этот результат.
- Публичного релиза и публикации в Hub нет. Лицензия и происхождение основы сохранены.
