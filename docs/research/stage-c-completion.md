# Этап C: понятная память — итог

Дата: 2026-10-30. Выпуск **0.1.5**. C0–C5 завершены в доступном и проверенном объёме. Это не утверждение о готовой привязке проектов/сессий или миграции личных данных.

| Подэтап | Результат | Доказательства |
|---|---|---|
| C0 | Проверена схема старого плагина, выбран отдельный владелец Companion | [Совместимость](memory-compatibility.md) |
| C1 | Один писатель, атомарное хранение, revision, приоритет ручных правок, session в RAM | [Хранилище](memory-c1-check.md) |
| C2 | Поиск, добавление, исправление, забывание и экспорт через панель | [Экран памяти](memory-c2-check.md) |
| C3 | Бюджетированный подбор общей памяти перед ответом, количество фактически подставленных записей | [Recall и нативный чат](memory-c3-check.md) |
| C4 | «Запомни / исправь / забудь» и предложения с подтверждением в панели, запрет сохранения и защита ручных правок | [Команды и приёмка](memory-c4-check.md) |
| C5 | Выборочный перенос offline-копии SQLite v2/JSON, резервная копия, откат и повтор без дублей | [Перенос и приёмка](memory-c5-check.md) |

Пользователь управляет записями через один экран. Записи старого persistent-memory не читаются автоматически. Предложение из чата само по себе не сохраняет факт: его нужно проверить и подтвердить в панели. Подстановка, предложения и интернет включаются раздельно; отдельной генерации для памяти нет.

В чат доступна **только global**. Project сохраняется с областью и не попадает в чужой чат; без подтверждённого стабильного ID чата его подстановка блокируется. Session хранится только в RAM и не мигрирует как постоянная память. Удаление прекращает новую подстановку, но не стирает старые сообщения, summaries и экспортированные копии.

Финальный набор: **170 тестов / 30 файлов**, typecheck/build, Edge UI для переноса и регрессии прежних экранов. C5 проверен с текущей уже загруженной 12B через SDK/препроцессор: импорт → правильный факт в ответе → откат → ноль refs → обычный ответ. Нативная совместимость с context-compressor ранее проверена в C3/C4; в C5 hooks не менялись, тяжёлая компрессия и 26B повторно не запускались. Установочный цикл и packaged runtime указаны в [машинном отчёте C5](../../reference/memory-c5-check.json).

Пользователь подтвердил отсутствие прежних записей — личный перенос не требуется. Проверялись только вымышленные копии; личная БД и переписки не использовались. Исходник старого плагина не изменяется; запись Companion выполняет единственный владелец. Откат переноса ограничен следующей постоянной правкой, чтобы защитить новые изменения.
