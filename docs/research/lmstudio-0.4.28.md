# LM Studio 0.4.28 — проверка списка изменений

Проверено **1 ноября 2026** по [официальному changelog LM Studio](https://lmstudio.ai/changelog/lmstudio).

- Build 1 исправляет разбор шаблона чата для модели Flint.
- Build 2 исправляет на macOS сценарий «Restart to apply update», который открывал прежнюю версию вместо установки обновления.

В этом списке не заявлены новые API памяти, идентификации чатов, документов или препроцессоров. По списку изменений нет основания считать решённой проблему сохранения карточек в Companion. Нативную совместимость с 0.4.28 нужно подтвердить отдельной проверкой; этот обзор не является результатом live-теста SDK на обновлённой установке. Модель, runtime и установленный LM Studio в рамках обзора не менялись.
