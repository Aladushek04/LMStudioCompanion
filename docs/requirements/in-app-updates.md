# Обновление из окна Companion — будущая возможность G

Статус: требования, **не реализовано в 0.1.5**. Пользователь спросил о возможности обновляться без ручного перехода на GitHub. Исходная основа уже есть: проверка manifest, отдельные версии, блокировка работающего host и откат в packages/host/src/install.ts; установочный цикл проверяет scripts/check-release.mjs.

## Пользовательский сценарий

В панели: **«Обновления» → «Проверить» → версия и изменения → «Скачать» → «Установить и перезапустить»**. Переходить на сайт вручную не требуется; интернет для проверки и скачивания нужен. Без сети остальное приложение продолжает работать, а панель объясняет, что обновление не проверено.

Получать только опубликованные обычные GitHub Releases; drafts, prereleases и локальные сборки подэтапов не предлагать. Сравнивать версию, платформу и совместимость данных. Автоматическую установку без подтверждения не включать.

## Основа реализации и границы

- Метаданные и архивы брать из официального репозитория; использовать проверяемый ZIP для Windows x64, SHA-256 и внутренний release-manifest. Не принимать произвольный URL от модели или документа. Секрет владельца репозитория клиенту не нужен.
- Скачивать в отдельную временную папку, показывать прогресс и отмену. Проверять файл целиком до применения. При обрыве, неверном хеше, нехватке диска или несовместимости не менять рабочую версию.
- Текущий installer блокирует обновление, пока host работает. Поэтому проверка и скачивание могут идти при открытой панели, а применение — через отдельный локальный помощник после корректной остановки Companion. Не пытаться захватить собственную блокировку из ещё работающего host.
- Сохранить data, пользовательские настройки и возможность вернуться к предыдущей версии. Миграции данных требуют резервной копии и проверки обратной совместимости; откат программы не означает безусловный откат данных.
- Если выполняется операция, предложить дождаться её завершения. Не прерывать генерацию LM Studio, не менять модель, чужие плагины и настройки чатов.
- Первый поддержанный вариант — установленная панель. Для переносного запуска и исходников явно показывать доступный способ обновления; не обещать его до отдельной проверки.
- Веб-плагин, Python-окружение и модельные runtime не обновлять молча вслед за панелью. Состав единого обновляемого комплекта и согласованные версии модулей закрепить в G до реализации.

## Будущая приёмка

Проверка без сети; уже актуальная версия; новая совместимая версия; отмена и обрыв загрузки; плохой хеш; не хватает места; активная операция; перезапуск и восстановление; ошибка установки с сохранением предыдущей версии и данных. Проверять в отдельном тестовом профиле, без личной памяти и чатов.
