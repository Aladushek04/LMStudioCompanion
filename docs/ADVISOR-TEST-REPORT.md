# Проверка советника 0.1.0

Дата: 2026-10-29. Windows, RTX 4060 Ti 16 ГБ, i5-12400, около 32 ГБ RAM. LM Studio 0.4.26, CLI установлен локально. Проверяется автономный модуль `packages/advisor`; остальные будущие функции проекта этим отчётом не подтверждаются.

## Автоматические проверки

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File packages\advisor\tests\Run-Tests.ps1`: **21 проверка**.

Покрыты: GiB/GB и ANSI; оценки CLI в stderr; неизвестный/ошибочный результат; память занята другими процессами; физический бюджет GPU; консервативный бюджет RAM; неполная телеметрия; несколько GPU; embedding-фильтр и metadata контекста; выбор сбалансированного кандидата; аргументы с пробелами, кавычками, Unicode и завершающими слешами; bounded timeout; дочерний процесс с унаследованными output pipes; ошибка дочерней команды; отмена до запуска; недоступный CLI; чтение финального отчёта после завершения worker.

`powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File packages\advisor\Advisor.ps1 -SmokeTest`: успешно созданы элементы Windows Forms. C#-host собран установленным компилятором .NET через Build.ps1, зависимости не скачивались.

## Реальные сухие оценки

Оценки выполнялись при уже загруженной 12B с контекстом **64000**. Данные о свободной памяти меняются от запуска к запуску; программа показывает фактический snapshot. В рамках оценки ни одна модель не загружалась и не выгружалась.

| Модель | Контекст | GPU Offload | Оценка GPU | Оценка всего | Вывод |
|---|---:|---:|---:|---:|---|
| 12B Q4_K_M | 16384 | 100% | 9,74 ГиБ | 9,74 ГиБ | По ёмкости подходит; сейчас нужно освободить память |
| 12B Q4_K_M | 32768 | 100% | 12,23 ГиБ | 12,23 ГиБ | Предложен как сбалансированный кандидат |
| 12B Q4_K_M | 65536 | 100% | 17,20 ГиБ | 17,20 ГиБ | Не помещается с резервом при этих параметрах оценки |
| 26B Q4_K_M | 16384 | 100% | 18,56 ГиБ | 18,56 ГиБ | Мало запаса |
| 26B Q4_K_M | 32768 | 75% | 15,33 ГиБ | 19,85 ГиБ | Мало запаса |
| 26B Q4_K_M | 32768 | 50% | 10,81 ГиБ | 19,85 ГиБ | Предложен кандидат; сейчас нужно освободить память |

Для 26B проверены семь кандидатов, включая полную выгрузку 16К/32К/64К, затем 75% и 50% при 16К/32К. Это сухая оценка 26B, не испытание её генерации или скорости.

Оценки CLI могут отличаться от реальной загрузки с другими KV/Flash/batch/runtime-настройками. Сам факт, что пользователь уже работает с 64000, не опровергается строкой про стандартную оценку 65536.

## Проверка интерфейса

Запущен `Advisor.exe`; через native UI проверены список моделей, сведения GPU/RAM/CPU, кнопка оценки, итоговые таблицы для обеих Gemma, выбор строки рекомендации и сброс старых результатов при выборе другой модели. Окно остаётся отзывчивым, вычисления выполняются в отдельном worker. В главном сценарии имена внутренних функций не требуются.

После копирования в `G:\Projects\LMStudioCompanion` там повторно выполнены все 21 проверки и UI smoke-test. Отдельно запущен exe именно из G:, проверены обновлённое окно, отмена посреди оценки («Проверка отменена. Итоговая рекомендация не готова.») и возможность повторного запуска. Действующая 12B осталась загружена с контекстом 64000 и parallel=1.

## Независимый review и исправления

Отдельный reviewer прочитал весь новый код в режиме read-only. Критических проблем не нашёл. Выявил гонку между финальной записью worker и остановкой timer: исправлено обязательным чтением terminal-report после наблюдаемого завершения процесса; проверено RED→GREEN. Кнопка подробностей также выключается при смене модели.

Reviewer отдельно не оценивал фактическую точность CLI и UI-layout; они проверялись основным агентом. Условный риск зависания при унаследованных output pipes воспроизведён отдельной проверкой и исправлен остановкой собственного дерева процессов и ограниченным ожиданием потоков. Вне тестов прямое применение настроек и бенчмарки не выполнялись и не входят в версию.
