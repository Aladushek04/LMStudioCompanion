# Состояние проекта — 1 ноября 2026

Главный ориентир — этот файл и [roadmap](ROADMAP.md). Отчёты в research/ сохраняют результаты конкретных проверок; старое описание в историческом отчёте не означает текущее состояние всего проекта.

Последнее уточнение CORE-2: пользователь подтвердил сохранение, сохранность после перезапуска и отрицание. В проверке цитаты модель выдала неподтверждённое заявление о второй активной метке, защита скрыла ответ. В `0.1.2-core2` основной ответ получает проверенный результат отсутствия записи; полный SDK-сценарий цитаты прошёл. Нативный повтор пользователем ещё ожидается.

**Текущее направление:** полноценный **Companion Core**, [CORE-0–CORE-7](plans/07-companion-core-stages.md). CORE-0/CORE-1 готовы; **CORE-2 реализован, пользователь подтвердил сохранение и запись в панели**. Сохранность после перезапуска также подтверждена; остальные нативные сценарии ожидают проверки. Текущая работа останавливается на CORE-2; CORE-3 не начинается автоматически. По решению пользователя развитие документов **приостановлено до завершения и приёмки всего Core**. D0–D3 сохраняются; D4/D5 возобновляются только отдельным поручением после Core.

## Релиз и исходники — разный объём

Публичный [v0.1.5](https://github.com/Aladushek04/LMStudioCompanion/releases/tag/v0.1.5) выпущен после A–C. Его ZIP не содержит более поздний экран документов D2/D3 и не заменяется сборкой из новых исходников под тем же именем.

`main` — актуальные принятые исходники, включая D0–D3. Следующий публичный релиз — после полной приёмки D, по [правилам выпуска](RELEASING.md). Для будущих изменений используются отдельные рабочие ветки; завершённая ветка удаляется после слияния с сохранением истории.

## Что проверено последним

CORE-2: **420/420** отдельных тестов Core на Node 24.22.2/25.5.0, **255/255** общих тестов на Node 24.22.2, TypeScript и обе сборки. Кандидат `0.1.2-core2` сохраняет общую заметку сразу по просьбе текущей LLM; итог из квитанции владельца, повтор/конфликт/ошибка/отмена/неизвестный результат различаются. Пользователь подтвердил сохранение, запись в панели и сохранность после restart; остальные нативные сценарии ещё не подтверждены. Чужие dirty-файлы сохранены и исключены из коммитов, ревью авторское без субагентов. [Точные результаты, ограничения и тестовые фразы](research/core-2-check.md). Историческая приёмка цикла — [CORE-1](research/core-1-check.md).

Исправления интерфейса памяти от 1 ноября: явные результаты обновления списка/предложений с временем и количеством; загрузка, ошибки и повтор; технические пояснения перенесены в раскрываемую справку. Изменения относятся к текущим исходникам, архив v0.1.5 остаётся прежним. Проверки зафиксированы в [отчёте](research/memory-feedback-check.md).

Проблема старого capture: модель может сказать «запомнил», хотя предложения нет. Старый companion-web сам не получил нового владельца ответа. Кандидат CORE-2 подтверждает сохранение по квитанции, подавляет свободный текст хода записи и проверяет обычный ответ при пропущенном намерении. Отсутствующий вызов, отказ/ошибка, повтор, источник/цитата, отмена и потеря ответа проверяются исполняемыми тестами. Первый нативный тест выявил ошибку разбора общего поля SDK с рассуждением; в `0.1.1-core2` используется итоговый текст без рассуждения. Реальная SDK-проверка текущей Gemma с временным owner и restart прошла. Затем пользователь подтвердил в нативном чате квитанцию и одну запись «проверочная метка — МАЯК-731» в панели. После перезапуска панели пользователь подтвердил: запись осталась на месте. Остальные нативные сценарии ещё не подтверждены. [Проверки и сценарии](research/core-2-check.md). Карточки остаются CORE-3.

При завершении D3: **243/243 теста в 39 файлах**, typecheck/build, Edge для D3/D2/обзора/памяти. Нативная проверка на уже загруженной 12B подтвердила точные фрагменты, ограничение разделом и токенные измерения без генерации/загрузки моделей. Итоговое ревью D3 выполнено автором без субагентов; завершённого независимого ревью нет.

Лексический baseline: опорный фрагмент для 10/10 ответимых вопросов, no-match для 4/5 неответимых. Найденный текст не гарантирует наличие ответа. Страницы PDF не выдумываются, OCR не включён, бюджет панели проверяется на пустой истории — это ещё не бюджет действующего чата.

## Чистота репозитория

Git содержит исходники, инструкции, тестовые fixtures, лицензии и отчёты приёмки. `Advisor.exe` — намеренно включённый запускатель автономного советника. Исторические отчёты и небольшие тестовые PDF — проверяемые материалы проекта, а не временные файлы.

Зависимости, runtime, dist/, локальные ZIP, кэши, временные рабочие каталоги, data/ и backups/ исключены из Git. Очистка кэшей не удаляет пользовательские данные, окружения, установленные копии или архивы релизов. История Git и опубликованный v0.1.5 сохраняются.
