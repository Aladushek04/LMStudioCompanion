Первый публичный выпуск **LM Studio Companion** для **Windows x64**, после приёмки этапов **A–C**. Чат остаётся в LM Studio. Это версия развивающегося проекта с ограничениями, перечисленными ниже.

## 📥 Что скачать

В разделе **Assets** выберите **LMStudioCompanion-0.1.5-win-x64.zip**. Рядом находится **.zip.sha256** для проверки целостности. Автоматические Source code (zip/tar.gz) — исходники, а не готовая программа.

## ✨ Что включено

- Локальная панель подключения и диагностика.
- Установка, обновление, откат и удаление панели с сохранением пользовательских данных.
- Экран памяти: поиск, добавление, исправление, забывание и экспорт.
- Общая память перед ответом и команды сохранения/исправления/забывания с подтверждением в панели — при отдельно подключённом companion-web.
- Перенос выбранных записей из offline-копии persistent-memory с резервной копией и откатом до следующей постоянной правки.
- Автономный советник по параметрам модели: только оценки, без изменения настроек и загрузки моделей.

## 🚀 Как запустить

1. Распакуйте архив в отдельную папку.
2. Откройте **Install-Companion.cmd**, подтвердите установку.
3. Откройте **Start-Companion.cmd** в папке установки и оставьте консоль открытой. Остановка — Ctrl+C.

Можно запустить Start прямо из распакованной папки без установки. Node **24.22.2** включён; npm и Docker для самой панели не нужны. Перед обновлением существующей установки остановите Companion; не удаляйте data.

**Плагин чата и веб-окружение не входят в этот ZIP.** Companion-web revision 3 подключается отдельно; для веба нужно подготовленное Python-окружение. Реализованные чтение сайтов, поиск, веб-изображения и источники проверены с context-compressor, но единый переносимый комплект всех модулей относится к будущему G. Одна установка панели не включает эти функции в чате автоматически.

## ℹ️ Ограничения

- В чат подключается только общая память. Проектные записи хранятся без подстановки; временная память чата пока не подключена.
- Удаление факта и откат переноса не стирают старые сообщения, сводки сжатия и отдельные экспорты.
- Работа с документами D0–D5 только запланирована. Применение профилей, управление Thinking и обновление из окна приложения ещё не реализованы.
- Личная память и переписки в комплект не включены. 26B не проверялась; результаты текущей 12B не переносятся на неё автоматически.

## ✅ Проверки

170 тестов в 30 файлах, typecheck/build, браузерные сценарии и 12 установочных проверок. Проверки C5 выполнены на вымышленных данных; импорт → recall текущей 12B → откат. Сборка перед публикацией повторно проверена установочным циклом и контрольными суммами.
