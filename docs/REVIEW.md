# Независимая проверка проектного решения

Дата: 2026-10-29. Выполнена отдельным агентом в режиме read-only, без запуска LM Studio и чтения личных данных. Проверялись проектное решение, очередь, решения и согласованность планов; это не code review будущей реализации.

Проверка выявила два существенных вопроса. Они решены как явные предложения автора плана:

1. **Привязка проекта к чату.** Проект фиксируется на первом управляемом ходе; выбор другого проекта действует на новые чаты. Старый чат продолжает прежний проект, иначе его история могла бы переносить факты между проектами. При отсутствии доказанного стабильного chat ID scoped auto-injection выключена. Добавлены контракт bindChatScope, проверка capability и тест смены default без rebind.
2. **Граница временной памяти.** Session — конкретный чат в текущем запуске Companion, со случайным sessionId и хранением только в RAM. Перезапуск host очищает её. Закрытие только LM Studio не считается завершением host. Контракт MemoryRecord и тесты дополнены sessionId; старые временные записи не мигрируются.

Остальные значимые технические неопределённости заранее отнесены к этапу 00. Голос исключён последовательно. Уточнения внесены в DESIGN.md, планы 00/03, DECISIONS.md и ACCEPTANCE.md; после этого выполнена проверка ссылок и структуры документов.
